What the product does

Core features

Privacy-first AI chat

Users can chat with AI inside a dedicated desktop app and configure their preferred Gemini model for daily use.

Screenshot analysis

Users can capture a selected screen region and send it to the AI assistant for image-based analysis.

Screen share protection

The application uses Windows display affinity features to stay hidden from common recording and sharing workflows.

Cloud-synced preferences

User settings such as model selection, opacity, theme, and profile information can be synced for convenience.

Subscription management

The app supports paid Pro subscriptions with automatic status tracking after successful payment.

Email notifications

Payment confirmations and promotional updates can be sent when the user provides a valid email address.
