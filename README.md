# Website Deployment

This folder contains a minimal business website for `Incognito AI Pro` that is intended to help with payment gateway review and basic public product presence.

## Pages included

- `index.html`
- `privacy.html`
- `terms.html`
- `refund.html`
- `shipping.html`
- `contact.html`

## Quick Netlify deploy

1. Push this repository to GitHub.
2. Sign in to Netlify.
3. Import the repository.
4. Keep the publish directory as `website`.
5. Deploy.

The root `netlify.toml` file already points Netlify to this folder.

## Before submitting to Razorpay

- Replace any placeholder wording that you want to make stricter or more business-specific.
- Confirm your public repository links are correct.
